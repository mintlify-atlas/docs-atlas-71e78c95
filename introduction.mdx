The Khmer Physics Handbook is a Grade 12 physics textbook written entirely in Khmer, with Khmer numerals used throughout — in page numbers, section headings, figure labels, and equations. It is typeset with XeLaTeX and dressed in a custom sakura theme: rounded boxes, floral dividers, and a palette deliberately chosen to make the book feel warm and inviting rather than institutional. It exists for one reason: Cambodian students deserve a high-quality physics resource in their own language, and they should never have to pay for it.

## Why It Exists

Physics education in Cambodia has long relied on materials that are either in a foreign language, visually austere, or locked behind a paywall. This project compresses 48 volumes of syllabus content into pages students will actually want to open. Every design decision — the sakura aesthetic, the Khmer numeral system, the open license for compiled PDFs — was made with the student in mind.

<Note>
  The Khmer Physics Handbook is built exclusively with **XeLaTeX**. pdfLaTeX cannot handle Khmer OpenType shaping and will fail. The engine is non-negotiable.
</Note>

## What It Covers

The handbook currently compiles to a single `main.pdf` of **83 pages** across three chapters. Figure numbering runs continuously from រូបទី១ through រូបទី៤១, and equations run from (១) through (២៩) — no per-chapter restarts.

## Current State

The latest tagged release is `v1.0.0-alpha.15`. Chapter 3 is the active frontier: Lessons 1–3 are fully written with derivations, photos, and vector graphics; Lesson 4 (ចរន្តឆ្លាស់ / alternating current) has just opened. The roadmap for what comes next — AC circuit parameters, RMS values, impedance, power factor, and resonance — is tracked in the changelog.

## The Build Output

The entire book assembles into one file:

```text
main.pdf   ← the deliverable; 83 pages, checked into the repo (not LFS)
```

Building is one command on any platform:

```bash
# Linux / macOS
bash build.sh
```

```bat
rem Windows
build.cmd
```

Both scripts use `latexmk`, which handles the two-pass compilation needed for the table of contents and page references automatically. The `.latexmkrc` at the root of the repository pins the engine to XeLaTeX, so no `-xelatex` flag is required.
