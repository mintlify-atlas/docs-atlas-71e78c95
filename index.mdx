The Khmer Physics Handbook is an open-source Grade 12 physics reference written entirely in Khmer with Khmer numerals throughout. Built with XeLaTeX and a custom sakura-themed design system, it delivers 83 pages of physics content — kinetic theory, wave mechanics, and electromagnetism — in a format students actually want to open.

This documentation covers how to build the PDF from source, how to contribute new content, and how to use the LaTeX macro library that powers the handbook's design.

## Quick build

<Steps>
  <Step title="Install Git LFS and clone">
    ```bash
    git lfs install
    git lfs clone https://github.com/airiharuki/physics_textbook.git
    cd physics_textbook
    ```
  </Step>
  <Step title="Install fonts onto your system">
    Copy all font files from `fonts/` to your system font directory. On Linux: `~/.fonts/` then run `fc-cache -fv`. On Windows/macOS: double-click each `.ttf` to install.
  </Step>
  <Step title="Build the PDF">
    <CodeGroup>
    ```bash Linux / macOS
    bash build.sh
    ```
    ```bat Windows
    build.cmd
    ```
    </CodeGroup>
    Output is `main.pdf` in the repo root.
  </Step>
</Steps>

<Note>
  The handbook uses **XeLaTeX** exclusively — pdfLaTeX cannot handle Khmer OpenType shaping and will fail. Make sure your TeX distribution includes `latexmk` and `fontspec`.
</Note>

The sakura theme is defined entirely in `preamble.tex`. Every color, font, box style, floral divider, and page decoration is available as a named macro — no per-chapter setup needed.
